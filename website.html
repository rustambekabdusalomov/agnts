04 Privacy

Your code stays on your machine.

hiro is installed on your own server or computer. No strangers, no shared cloud, no copy of your repository on our side.

Self-hosted

One machine with Docker. Your repositories are stored and run there, and nowhere else.

A fresh box per run

Each task runs in an isolated container with limited network, removed when the run ends.

Encrypted tokens

Jira, Git and Claude tokens are encrypted on your machine and never shown again.

Nothing ships without you

The agent can't push or deploy. hiro pushes only after you approve, and deploys only when you press the button.

08 FAQ

Questions developers ask.

Does my code leave my machine?

Your repositories live and run only on your server or computer. While hiro works on a ticket, Claude Code sends the relevant code to Claude through your own Claude plan, exactly as when you use Claude Code yourself. Nothing is sent to us.

Can hiro push code or deploy on its own?

No. The agent inside the container can't push or deploy. hiro pushes only after you approve the diff, and production deploys happen only when you press the button.

What happens when a ticket is unclear?

hiro reads the code first, then asks short questions with options. Coding starts only after you answer, so you don't get invented features.

Why do I need my own Claude plan?

hiro runs Claude Code on your plan, so you control the model costs and there are no surprise bills from us. hiro tracks your limits and pauses before they run out.

Does it work for side projects without Jira?

Yes. You can create tasks for side projects directly in hiro.

Is it only for senior developers?

No. Juniors use it to move faster and learn from the diffs; seniors use it to clear routine tickets and stay on the hard problems.
