# Shared translations

`en/`, `ru/` and `uz/` are the source of truth for UI text in both clients.
Each folder holds one file per area (`dashboard.json` contains
`{"dashboard": {...}}`). English defines the keys; the other two must have
exactly the same keys (`make i18n-check` enforces it).

- Values use ICU MessageFormat: `{name}` placeholders and
  `{count, plural, one {…} other {…}}` plurals. Russian plurals need
  `one`, `few`, `many` and `other`.
- Keys are nested by area (`auth.title`). Keep leaf names camelCase.
- The admin panel (vue-i18n) reads these files directly, with an ICU compiler.
- The mobile app gets ARB files generated by `make gen`
  (`auth.title` becomes `authTitle`).

`demo/strings.json` holds the 646 English → RU/UZ strings extracted from the
HTML demos, keyed by the English text. They are raw material: when a page is
ported in phase 2, move the strings it needs into the keyed files and delete
them from `demo/`. The demo's regex rules for durations and plurals were not
extracted; plurals are expressed with ICU in the keyed files instead.
