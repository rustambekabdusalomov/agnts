# Лимиты тарифа

agnts работает на вашей подписке Claude. Здесь видно, какая её часть уже использована.

## Текущая сессия

Использование в текущем 5-часовом окне и время сброса. Те же цифры внизу боковой панели.

## Эта неделя

Использование в недельном окне. Сюда входит и ваше собственное использование Claude и Claude Code на том же аккаунте.

## У самого лимита

Выше 80% появляется предупреждение. Если лимит закончился во время запуска, agnts встаёт на паузу, сохраняет ветку и продолжает после сброса.

## Откуда цифры

Claude Code сообщает лимиты во время каждого запуска. Когда agnts простаивает, их обновляет крошечный служебный запуск.

## Расход по тикетам

Лимиты выше — для всего аккаунта. «Тикеты по расходу» показывает тикеты, которые израсходовали больше всего за последние 7, 30 или 90 дней, с самым дорогим этапом и долей каждого за период. Порядок — по оценке стоимости от Claude Code, которая правильно учитывает дешёвый кэш. Откройте тикет, чтобы увидеть токены по этапам; в списках тикетов тоже видны токены каждого.
