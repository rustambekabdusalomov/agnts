# Лимиты тарифа

hiro работает на вашей подписке Claude. Здесь видно, какая её часть уже использована.

## Текущая сессия

Использование в текущем 5-часовом окне и время сброса. Те же цифры внизу боковой панели.

## Эта неделя

Использование в недельном окне. Сюда входит и ваше собственное использование Claude и Claude Code на том же аккаунте.

## У самого лимита

Выше 80% появляется предупреждение. Если лимит закончился во время запуска, hiro встаёт на паузу, сохраняет ветку и продолжает после сброса.

## Откуда цифры

Claude Code сообщает лимиты во время каждого запуска. Когда hiro простаивает, их обновляет крошечный служебный запуск.
