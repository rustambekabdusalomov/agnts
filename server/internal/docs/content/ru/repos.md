# Репозитории

Код, с которым может работать agnts. Каждый запуск клонирует репозиторий в новый контейнер на вашем сервере.

## Источники

Репозитории Jira получают тикеты из проекта Jira, репозитории Plane — задачи из проекта Plane. Репозитории ваших проектов получают задачи, созданные в agnts.

## Проверки

После разработки запускаются сборка, линтер и тесты. Тикет попадает на ревью, только если они прошли.

## CLAUDE.md

Файл в корне репозитория со структурой, соглашениями и командами тестов. Без него agnts тратит больше шагов, чтобы разобраться.

## Изменение

Нажмите на репозиторий, чтобы изменить URL, ветку по умолчанию или команды.

## Превью

Укажите команду запуска и порт, и agnts сможет снимать скриншоты изменений интерфейса до вашей проверки. Команда выполняется в контейнере запуска (установка, сборка, запуск); agnts ждёт, пока порт ответит. Файлы интерфейса определяют, какие изменения получают скриншоты. Переменные окружения — строки KEY=value, например адрес staging API; они хранятся зашифрованными, показываются только по именам и видны приложению и agnts, поэтому используйте только тестовые учётные данные. Хосты, к которым обращается приложение, добавьте в Настройки → Превью → Разрешённые хосты.

## Тулчейны

Языки и инструменты сборки, которые ставятся в каждый запуск, например go@1.24, node@20 или python@3.12. agnts определяет их по файлам репозитория (mise.toml, .tool-versions, go.mod, .nvmrc, pyproject.toml, Cargo.toml, pom.xml, global.json, Gemfile и другим) и обновляет, когда эти файлы меняются. «Определить» заново читает основную ветку; «Спросить Claude» дополнительно читает README и файлы CI, если сканирование не нашло команд. Если изменить список вручную, автоопределение его не трогает. Каждая версия ставится один раз и общая для всех запусков; у каждого репозитория свой кеш пакетов между запусками.

## Дополнительно

Образ запуска заменяет стандартный образ для этого репозитория — для системных библиотек или SDK, которые тулчейны не дают (Android, Flutter); соберите его на сервере FROM agnts-runner. Память увеличивает память контейнера для тяжёлых сборок. Окружение сборки — строки KEY=value, например токены приватных реестров; оно хранится зашифрованным, показывается только по именам и доступно Claude во время работы, поэтому используйте токены только для чтения.
