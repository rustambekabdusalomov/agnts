# Логи

Каждый шаг hiro записывается. Здесь видно, куда уходит время и почему запуски останавливаются.

## Статистика

Сколько запусков начато, сколько дошло до ревью, среднее число шагов на тикет и сколько запусков остановилось или встало на паузу.

## Куда уходит время

Среднее время на каждом шаге. Синий — работает hiro, жёлтый — время ожидания вас. Учитываются только завершённые шаги.

## Типы событий

Смена статусов, вызовы инструментов Claude Code, команды hiro, ваши действия, показания лимитов и ошибки.

## Фильтры

Фильтруйте по типу или ключу тикета либо показывайте только ошибки. Нажмите на строку, чтобы увидеть исходные данные.

## Экспорт

«Экспорт JSON» копирует отфильтрованные события для анализа в другом месте.
