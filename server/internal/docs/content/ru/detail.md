# Страница тикета

Путь одного тикета от получения до отправки. Шкала вверху показывает, где он сейчас. Шаги-ромбы — это места, где hiro ждёт вас.

## Вопросы

hiro сначала читает код и спрашивает только то, что не может решить сам. Выберите вариант или напишите свой ответ, затем нажмите «Начать разработку».

## Модели для этого тикета

Замените модель по умолчанию только для этого тикета, например Opus для сложного изменения или Haiku для небольшого.

## Лог в реальном времени

Пока hiro работает, видно каждый шаг, модель, число шагов и использование сессии. «Остановить запуск» прерывает работу и сохраняет ветку.

## Ревью

Прочитайте, что сделал hiro, проверьте тесты и изменения. «Одобрить и отправить» делает коммит от вашего имени. «Запросить изменения» передаёт ваш комментарий в ту же сессию. «Отклонить» удаляет ветку.

## Когда hiro останавливается

После повторных падений тестов или из-за лимита hiro останавливается, а не гадает. Добавьте указания и повторите или возьмите тикет себе.

## История и лог запуска

История показывает ключевые моменты. Лог запуска — все события по шагам, а «Открыть в логах» показывает их с фильтрами.
