# Задачи

Задачи — для репозиториев вне Jira, например ваших личных проектов. Они проходят те же шаги, что и тикеты Jira.

## Новая задача

Выберите репозиторий, опишите нужный результат (при необходимости приложите скриншоты, макеты или файлы), задайте приоритет и способ старта: сначала вопросы, сразу разработка или оставить в очереди.

## После вашего одобрения

Для каждой задачи выберите, открывает ли agnts пул-реквест или отправляет сразу в main. Без вашего ревью он ничего не отправляет.

## Репозитории

Добавьте репозиторий с URL для клонирования, префиксом для номеров задач и командой тестов, которая должна проходить.

## Изменение

Пока задача в очереди, её можно изменить или удалить на её странице.

## Несколько репозиториев

Выберите несколько репозиториев или группу, если одно изменение затрагивает их все (API и приложение, которое его вызывает). agnts работает над всеми в одном запуске: каждый репозиторий — отдельная папка, его проверки идут в его папке, и каждый изменённый репозиторий получает свой коммит и pull request со ссылками на остальные. Репозиторий, который работа не изменила, pull request не получает. Задача считается слитой, когда слиты все открытые ею pull request; если один закрыт без слияния, она помечается как слитая частично. Если push не удался в одном репозитории, остальные остаются отправленными, а «Повторить» отправит оставшиеся.
