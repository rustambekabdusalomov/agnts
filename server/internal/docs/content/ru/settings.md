# Настройки

Как agnts подключается к вашим инструментам и ведёт себя во время запусков. Изменения применяются после «Сохранить изменения».

## Оформление

Тема и язык. Сохраняются в этом браузере и применяются сразу.

## Jira и GitHub

Откуда приходят тикеты, какую метку берёт agnts и от чьего имени делаются коммиты.

## Claude Code

Какая модель работает на каждом этапе, лимит шагов и тайм-аут, какие команды Claude Code можно и нельзя выполнять.

## Запуски

Значения по умолчанию для вопросов, продолжения после лимитов, порога для новых запусков и числа одновременных запусков.

## Превью

Скриншоты каждого изменения интерфейса в репозиториях с командой превью, модель, которая выбирает страницы и оценивает их, можно ли запускам кода самим смотреть на приложение, и дополнительные хосты для контейнеров запуска (например staging API вашего приложения).

## Уведомления

Сообщения в Telegram, когда что-то ждёт вас, запуск остановился или изменения отправлены.

## Секреты

Токены хранятся в окружении вашего сервера и никогда не показываются на этой странице.
