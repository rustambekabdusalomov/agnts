# Ticket page

Follow one ticket from pickup to push. The track at the top shows where it is. Diamond steps are where hiro waits for you.

## Questions

hiro reads the code first and asks only what it can't decide itself. Pick an option or write your own answer, then press Start coding.

## Models for this ticket

Override the default model for this ticket only, for example Opus for a hard change or Haiku for a small one.

## Live log

While hiro works you see each step, the model, turns used and session usage. Stop run halts it and keeps the branch.

## Review

Read what hiro did and check the tests and diff. Approve and push commits as you. Request changes sends your feedback into the same session. Reject discards the branch.

## When hiro stops

After repeated failed tests or a plan limit, hiro stops instead of guessing. Add instructions and retry, or take the ticket yourself.

## History and run log

History lists the main moments. Run log shows every event grouped by step, and Open in Logs shows them with filters.
