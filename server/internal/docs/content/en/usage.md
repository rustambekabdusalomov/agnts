# Plan usage

hiro runs on your Claude subscription. This page shows how much of it is used.

## Current session

Usage in the current 5-hour window and when it resets. The same numbers are at the bottom of the sidebar.

## This week

Usage in the weekly window. It includes your own Claude and Claude Code use on the same account.

## Near the limit

Above 80% you get a warning. If the limit is reached mid-run, hiro pauses, keeps the branch and resumes after the reset.

## Where the numbers come from

Claude Code reports limits during every run. When hiro is idle, a tiny refresh run keeps them current.
