# Plan usage

agnts runs on your Claude subscription. This page shows how much of it is used.

## Current session

Usage in the current 5-hour window and when it resets. The same numbers are at the bottom of the sidebar.

## This week

Usage in the weekly window. It includes your own Claude and Claude Code use on the same account.

## Near the limit

Above 80% you get a warning. If the limit is reached mid-run, agnts pauses, keeps the branch and resumes after the reset.

## Where the numbers come from

Claude Code reports limits during every run. When agnts is idle, a tiny refresh run keeps them current.

## Spend per ticket

The limits above cover the whole account. Tickets by spend ranks the tickets that used most of the plan in the last 7, 30 or 90 days, with each one's costliest stage and its share of the period. It ranks by Claude Code's cost estimate, which weighs cheap cache traffic properly. Open a ticket to see its tokens stage by stage; ticket lists show each ticket's tokens too.
