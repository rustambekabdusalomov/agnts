# Tasks

Tasks are for repositories outside Jira, like your side projects. They go through the same steps as Jira tickets.

## New task

Pick a repository, describe the result you want, set the priority and choose how to start: ask questions first, start coding right away, or keep it in the queue.

## After you approve

Choose for each task whether hiro opens a pull request or pushes straight to main. It never pushes without your review.

## Repositories

Add a repository with its clone URL, a key prefix for task numbers, and the test command that must pass.

## Editing

While a task is still in the queue you can edit or delete it from its page.
