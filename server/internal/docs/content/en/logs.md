# Logs

Every step hiro takes is recorded. Use this page to see where time goes and why runs stop.

## Stats

Runs started, how many reached your review, average turns per ticket, and how many runs stopped or paused.

## Where the time goes

Average time per step. Blue is hiro working, amber is time spent waiting for you. Only finished steps are counted.

## Event types

State changes, tool calls made by Claude Code, commands hiro ran, your actions, plan limit readings and errors.

## Filters

Filter by type or ticket key, or show errors only. Select a row to see its raw data.

## Export

Export JSON copies the filtered events so you can analyze them elsewhere.
