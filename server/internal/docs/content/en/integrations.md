# Integrations

The services hiro works with: Jira for tickets, and GitHub or GitLab for code. Each has its own page with connection status and options.

## Connecting

Paste an access token with the listed scopes. It's stored encrypted on your server and never shown again. Test connection checks it at any time.

## Permissions

Each git page shows which permissions the token has. Required ones must be granted for runs to work.

## Repository access

Turn a repository off to stop hiro from cloning or pushing to it, without removing it.

## Commits and pull requests

Who commits appear from, a Co-authored-by line, title format, draft mode, labels, reviewers and what happens after merge.

## Jira rules

Which projects are watched, the label, issue types and statuses hiro picks up, shown as the exact query it runs.

## Status updates and comments

How hiro moves tickets on your board and what it writes as comments.
