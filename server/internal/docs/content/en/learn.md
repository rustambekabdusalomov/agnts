# Learn

agnts writes the code, so you might not notice when a change brings in something your codebase never did before. After each push, agnts reads the change and explains what is new here.

## What becomes a lesson

A pattern, architectural boundary, algorithm, library, language feature or testing approach that the change relies on and the repository did not use before. Routine edits never become lessons, and most changes have none.

## Knowledge base

Each repository keeps its own list of concepts. agnts checks the code and that list before writing, so the same idea is taught once per repository.

## Quiz and progress

Every lesson ends with a few questions. Mark a lesson learned when you are done; the New view shows what is left.

## Cost

Lessons come from a short Claude run that waits until no ticket needs a worker. Turn it off or pick its model in Settings, or start it by hand from a finished ticket.
