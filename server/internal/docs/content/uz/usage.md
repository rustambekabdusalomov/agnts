# Tarif limitlari

agnts Claude obunangizda ishlaydi. Bu sahifa uning qancha qismi sarflanganini koʻrsatadi.

## Joriy sessiya

Joriy 5 soatlik oynadagi sarf va qachon yangilanishi. Xuddi shu raqamlar yon panel pastida ham bor.

## Shu hafta

Haftalik oynadagi sarf. Bunga shu akkauntdagi oʻzingizning Claude va Claude Code sarfingiz ham kiradi.

## Limitga yaqin

80% dan oshganda ogohlantirish chiqadi. Ish oʻrtasida limit tugasa, agnts pauza qiladi, branchni saqlaydi va yangilangach davom etadi.

## Raqamlar qayerdan

Claude Code har bir ishda limitlarni xabar qiladi. agnts boʻsh turganda ularni kichik yangilash ishi dolzarb saqlaydi.

## Tiketlar boʻyicha sarf

Yuqoridagi limitlar butun akkaunt uchun. «Sarf boʻyicha tiketlar» oxirgi 7, 30 yoki 90 kunda obunani eng koʻp sarflagan tiketlarni har birining eng qimmat bosqichi va davrdagi ulushi bilan koʻrsatadi. Tartib Claude Code narx bahosi boʻyicha, u arzon keshni toʻgʻri hisobga oladi. Bosqichma-bosqich tokenlarni koʻrish uchun tiketni oching; tiketlar roʻyxatida ham har birining tokenlari koʻrinadi.
