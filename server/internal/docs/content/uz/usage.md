# Tarif limitlari

hiro Claude obunangizda ishlaydi. Bu sahifa uning qancha qismi sarflanganini koʻrsatadi.

## Joriy sessiya

Joriy 5 soatlik oynadagi sarf va qachon yangilanishi. Xuddi shu raqamlar yon panel pastida ham bor.

## Shu hafta

Haftalik oynadagi sarf. Bunga shu akkauntdagi oʻzingizning Claude va Claude Code sarfingiz ham kiradi.

## Limitga yaqin

80% dan oshganda ogohlantirish chiqadi. Ish oʻrtasida limit tugasa, hiro pauza qiladi, branchni saqlaydi va yangilangach davom etadi.

## Raqamlar qayerdan

Claude Code har bir ishda limitlarni xabar qiladi. hiro boʻsh turganda ularni kichik yangilash ishi dolzarb saqlaydi.
